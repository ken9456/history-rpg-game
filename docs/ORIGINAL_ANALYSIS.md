# 原始遊戲分析與保留追蹤

分析對象為實際上傳的 `大航海時代_未知海域_簡易增強版(3).html`；用戶指令中的 `(2)` 與上傳檔名不同，本專案以實際提供的 `(3)` 為基礎。

- 原檔：354 行，99,661 bytes（UTF-8）。
- SHA-256：`f21c8d116669b59c1cf1d7b958f9cecb7de6a64140e141f69078a1dda575da76`。
- 原有核心：46×33 海格、每格 3°、38 個海岸多邊形（849 個座標點）、17 個起點／地標／港口、14 個一般事件、2 個主線事件、6 種操作／選擇小遊戲。
- 原航程：里斯本 → 好望角 → 馬林迪 → 卡利卡特。原檔沒有西方分支、麥哲倫篇、跨角色 RPG 對話、成就或排行榜。

## 原始碼中觀察到的限制與需防止的問題

1. `autosave()` 捕捉所有錯誤卻沒有提示；受限制的 iframe 或儲存空間不足時，學生可能誤以為已保存。
2. `savedSafe()` 只核對版本及 `revealed.length`，沒有驗證座標、資源、陣列內容或事件狀態。
3. `eventModal()` 在玩家作決定前便把事件加入 `storySeen` 並保存；關閉／重新載入頁面可能略過尚未完成的隨機事件。
4. 港口冷卻檢查分散於按鈕 `disabled`、`openDock()` 與 `force` 參數。一般UI有冷卻保護，但傳入 `force=true` 會繞過函式檢查；新引擎應集中驗證，避免新流程意外漏查。
5. 原得分把部分失敗、重新出發及重複行走轉成「熱誠」分。這能鼓勵弱生，但亦可能讓故意失敗或刷步數獲得較高分。
6. 原隨機池耗盡後會重置，事件及正面分數可重複累積。升級後應以獨立事件／方法作一次性計分。
7. 原每7步扣1補給、低補給每12步自動加3，加上眾多補給點，刻意降低了失敗率；升級應保留友善補救，但加入航程天數或資源代價及清楚回饋。
8. 原滑動地圖會反向移動船隻，而不是移動鏡頭；容易令觸控使用者意外航行。
9. 原`paint()`會在沒有航跡時直接寫入`S._trail`。新地圖渲染只讀取狀態，存檔由遊戲引擎管理。
10. 原航海時間完全由`1+step*2`推算，並非現實分鐘，也非真實歷史日程。新報告應分開標示遊玩時間與模擬航海日，排名不能過度懲罰閱讀較慢的學生。
11. 原疾病敘述提及「蔓延」，可能讓學生誤以為壞血病是傳染病；應表明為共同營養不足導致的健康困難，並區分當時理解與今日知識。
12. 原沒有成就、排行榜、角色立繪、表情、逐幕故事或三種結局；這些是新增功能，不能聲稱是原有功能。

## 地圖改版的直接保留證據

`map-data.js` 中的 `ORIGINAL` 是從上傳HTML的 `DATA` JSON 原樣抽取；前38個 `polys` 與原檔逐項相同。新 `land[y].slice(26)` 與原 `DATA.land[y]` 在全部33行完全相同。原17個地點只把 `x` 增加26，經緯度及原有航線沒有平移。

西方輪廓是手工繪製的簡化經緯度示意多邊形，沒有借用參考圖片。島嶼、停泊位置、3°格大小及補給距離均為教學用途，不能用作真實導航或航海日程證據。巴哈馬終點代表群島附近海域，不聲稱為已確定的1492年首登陸島嶼位置。

地圖沿用原 `paint()` 的層次：海面 → 海岸 → 經緯線 → 迷霧 → 航跡 → 港口 → 船隻／相鄰移動提示。新增層為岸邊淺水、BFS建議方向與畫外目標箭頭。保留原船圖的船體、桅杆和左右帆造型，再加旗幟及尾浪。沒有以獨立靜態圖片替換可互動地圖。
