## 史實、藝術創作與模擬的界線

- **史實摘要：** 上表核心年份、地理方向、不同社會原已存在，以及航行的正面與負面影響。
- **藝術創作：** 動漫立繪、衣服細節、王宮、港口和船上場景。它們表達時代氛圍，不是考古重建；歷史肖像亦不等於當事人的精確外貌。
- **虛構故事：** 年輕航海家、曙光號、杜阿爾特、伊妮絲、里奧、尤素夫、瑪拉、缺角海圖、人物性格和所有對話。這些人物不代表一支有史料證實的船員組合。
- **遊戲模擬：** 海格、縮略海岸、資源數值、事件機率、時間換算、可補給商船、重複補給、緊急救援與多重結局。不能用遊戲移動格數計算真實航程、停靠頻率或歷史死亡率。
- **教學推演：** 西方航線由共同遊戲基地出發，不能當作哥倫布歷史出發港的重現；哥倫布1492年從西班牙啟航。麥哲倫篇的兩次選擇用於體驗困難，不會改寫1521／1522年的歷史結果。

## 避免的常見誤解

1. 「未知」表示玩家或某些歐洲航海者尚不熟悉，不表示當地沒有人或沒有知識。
2. 沒有採用「大家以為地球是平的，麥哲倫才證明地球是圓的」的敘述。
3. 星盤不會直接提供完整經緯度；羅盤不是GPS。
4. 「堅持」不等於永遠繼續前進。暫停、求援、改航和回航都可以是有根據的決定。
5. 對探索精神的欣賞，不等於為殖民、掠奪或武力行為辯護。
6. 可讓學生指出資料館網站也可能採用較舊觀點；教師應交叉核對，並區分確定資料與爭議。
